# Catálogos institucionais

Os índices `formacoes.json` e `cases.json` são a **visão partilhada** de todas as formações e casos, não a distribuição dos conteúdos pagos.

- Código Fxx identifica uma **formação** e não se altera quando o programa evolui.
- Código Cxx identifica um **Case** e não muda ao ser usado noutra formação.
- `origem_formacao: F01` preserva o nascimento dos seis Cases na formação A Arquitectura da SuperInteligência Agêntica.
- `uso_em_formacoes` identifica contextos pedagogicamente confirmados. Disponibilidade para reutilização não equivale a inclusão automática em F02.
- `publicavel: false` protege referências em revisão até homologação explícita.

Não replicar os seis masters na pasta de cada formação; usar referências e fixar versões por release.
